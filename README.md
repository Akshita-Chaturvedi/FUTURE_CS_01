# FUTURE_CS_01
# OWASP Juice Shop – Security Assessment

This repository contains my complete vulnerability assessment of the **OWASP Juice Shop** web application.  
The project includes documentation, testing methodology, Burp Suite evidence, and a full PDF penetration testing report.

---

## 📌 Vulnerabilities Identified
- SQL Injection – Authentication Bypass
- Weak Authentication / Brute Force
- Reflected Cross-Site Scripting (XSS)
- Broken Access Control – Admin API Exposure
- Sensitive Data Exposure (Insecure API)
