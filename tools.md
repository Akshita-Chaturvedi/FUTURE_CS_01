# Tools Used

This document lists the tools used during the OWASP Juice Shop security assessment.

---

## 1. Burp Suite Community Edition
**Purpose:**
- Intercepting HTTP requests  
- Modifying and replaying login payloads  
- Testing SQL Injection  
- Testing access control flaws  
- Using Intruder for brute-force simulations  

---

## 2. OWASP ZAP
**Purpose:**
- Crawling the application  
- Passive scanning for common vulnerabilities  
- Observing request/response details  
- Generating spider scan logs  

---

## 3. Web Browser Developer Tools
**Purpose:**
- Viewing DOM changes  
- Tracking JavaScript execution  
- Testing XSS payloads in search and input fields  
- Monitoring cookies and storage
